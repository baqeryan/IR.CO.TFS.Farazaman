# تغییرات نسخه ۱۱۷

تاریخ انتشار: ۱۴۰۵/۰۷/۰۹ (2026-10-01)

- اصلاح فرم ثبت تخلف بخش تعهدات برای استفاده از کارفرما و قرارداد ذخیره‌شده هنگام انتخاب محدوده کاری.
- رفع پیام اشتباه «کارفرما را انتخاب کنید» در فرم تعهدات.
- اختیاری‌شدن فیلد توضیحات در تمام فرم‌های ثبت تخلف و عدم اجرای تعهدات.
- تغییر عنوان فیلد به «توضیحات (اختیاری)» و حفظ الزامی‌بودن تعداد/مقدار و آدرس.
