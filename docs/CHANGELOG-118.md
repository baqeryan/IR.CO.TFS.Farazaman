# تغییرات نسخه ۱۱۸

تاریخ انتشار: ۱۴۰۵/۰۷/۰۹ (2026-10-01)

- رفع توقف پیمایش خانه به تاریخچه روی صفحه میانی «امروز».
- اصلاح همگام‌سازی تب انتخاب‌شده پس از پایان Swipe یا انیمیشن Pager.
- حذف لودینگ تکراری داخل انتخاب‌گرهای فرم ثبت تخلف و نگه‌داشتن یک لودینگ عمومی.
- اصلاح اسکرول فرم تعهدات برای عبور محتوا از زیر کارت شیشه‌ای «بازدید فعال».
- کاهش فاصله بصری منوی پایین از لبه پایین صفحه با حفظ فضای امن Navigation Bar.
